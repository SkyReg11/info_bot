Telegram Bot — info_bot

Персональный Telegram-бот, разработанный на Python для получения информации о погоде, курс валют и новости. Проект включает в себя как функционал самого бота, так и набор автоматизированных тестов.

🛠 Стек технологий
Язык программирования: Python 3.x

Библиотека для бота: aiogram / pyTelegramBotAPI / telebot

Тестирование: Pytest / Unittest.mock

Среда разработки: PyCharm

Инструменты: Git, GitHub

⚙️ Функционал бота
При взаимодействии с ботом про помощи нажатии кнопок бот выдает информацию

Валидация входящих данных (защита от некорректного ввода)

Интеграция с внешним API для получения данных

🧪 Тестирование (QA)
В проекте реализовано автоматизированное тестирование для проверки корректности работы бота.

Написаны автотесты с использованием Pytest / Unittest.mock.

Проверены позитивные и негативные сценарии (например, ввод несуществующих команд).

Скриншот успешного прохождения тестов находится в файле Тест телеграм бота.png

🚀 Как запустить проект локально
Клонируйте репозиторий:
git clone https://github.com/SkyReg11/info_bot

Перейдите в папку с проектом и установите зависимости:
pip install -r requirements.txt

Создайте файл .env в корневой папке и добавьте туда ваш токен от Telegram (BotFather):
BOT_TOKEN=ваш_токен_здесь

Запустите бота:
bot.py
