# Telegram-бот - info_bot

Персональный Telegram-бот, разработанный на Python для получения информации о погоде, курсе валют и новостях. Проект включает в себя функционал самого бота и набор автоматизированных тестов для проверки его работоспособности.

## 🛠 Стек технологий
* **Язык:** Python 3.14
* **Библиотека для бота:** *aiogram, pyTelegramBotAPI, telebot*
* **Тестирование:** *pytest, unittest.mock*
* **Среда разработки:** PyCharm
* **Инструменты:** Git, GitHub

## ⚙️ Функционал бота
* При открытии бота выдает информацию с помощью кнопок.
* Проверка входящих данных (защита от некорректного ввода).
* Интеграция с API-интерфейсом для получения данных (погода, курсы валют, новости).

## 🧪 Тестирование (QA)
В проекте реализовано тестирование для проверки корректности работы бота.
* Написаны автотесты с использованием *pytest*.
* Проверены позитивные и негативные сценарии (например, ввод несуществующих команд).

## 🚀 Как запустить проект локально
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/SkyReg11/info_bot

2. Перейдите в папку с проектом и установите зависимости:
   ```bash
   pip install -r require.txt

3. Создайте файл .env в корневой папке и добавьте туда токен от Telegram (BotFather):
   ```bash
   BOT_TOKEN=ваш_токен_здесь

4. Запустите бота:
   ```bash
   bot.py
